J., Wollny, D. et al., *Inferring and perturbing cell fate regulomes in human brain organoids*, Nature 621, 365–372 (2023), [doi:10.1038/s41586-022-05279-8](https://doi.org/10.1038/s41586-022-05279-8). The authors' [Zenodo v5 record 15371701](https://doi.org/10.5281/zenodo.15371701) lists `ATAC_all_merged_srt.rds`, `RNA_all_merged_srt.rds`, `lines12_RNATAC16_26_integrated_v3scores_srt.rds` and `rna_matrices.tar.gz`. [Zenodo v4 record 13254037](https://doi.org/10.5281/zenodo.13254037) provides the time-course fragments archive. [Zenodo v3 record 7687749](https://doi.org/10.5281/zenodo.7687749) is identified by the v5 record as a source of further Seurat objects. The QC classifier separately uses a [public developing human cortex reference](https://cells.ucsc.edu/cortex-dev/).

The upload directory retains selected small inputs and intermediate checkpoints in `dataset/`. The source RNA/ATAC objects, extracted RNA counts, fragments and other files over 50 MiB were moved to the local sibling `grnm-main-large-data-local/`, preserving their relative paths; see `large_files_local_backup.tsv`. Public original objects can be downloaded from the Zenodo records above. Large project-generated matrices and checkpoints are distinct from public original objects. The project-specific prepared inputs, fitted checkpoints, candidate table, and outputs are not identical to the original authors' data deposit and require independent access and redistribution arrangements. See `data_manifest.tsv` for a size inventory.

The source paper and its published data records establish study-level provenance. Sample-by-sample mapping and the origin of each auxiliary or project-generated file require separate verification; original public data links do not reproduce the prepared reviewer bundle on their own. Check file validation details below and confirm permissions before distributing the prepared inputs.

## Local checks against the original study

The local `lines12_RNATAC16_26_integrated_v3scores_srt.rds` was previously checked against the matching file in [Zenodo v5](https://zenodo.org/records/15371701). This confirms the identity of that original object. The local `rnaMatrix.rds` contains 33,538 genes and 50,000 cells; its cell names and their order match the saved audit of the original RNA object and each cell's count total matches its original metadata (`nCount_RNA`; maximum difference zero). All 9,327 cells used by SCENIC are present in that RNA cell list and match the AUCell input order.

These checks establish identity for the integrated object and cell/count consistency for the extracted RNA matrix; count totals alone do not prove every individual matrix entry. The project-specific fitted results and selected 9,327-cell matrices are derived data rather than the original source objects.
