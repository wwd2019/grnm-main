# 投稿前核查

本项目使用 Fleck 等人发表的人类脑类器官数据。原论文、公开数据入口、当前上传包的文件范围及已完成的数据身份核查见仓库根目录 README 和 `01_data_provenance.md`。代码、输入表、结果和图的检查记录见 `validation.md`、`reviewer_audit.md` 与相应日志。

当前 GLI3 比较是事后定向、描述性的比较：HES4 在已有认识后加入评价范围；pando+GRN 使用 GRNBoost2 特征，且两个 Pando 结果与模型并非独立实验真值。3/10 和 2/10 是候选表命中数，不是校准概率或统计显著性。HES4、PAX6 已出现在 Our Pando 的边集中。Pando 区域检验的 `padj_min` 不是独立的 TF–gene 联合检验。两种 Pando 结果中 GLI3–HES4 系数方向不同，应进一步核查。

完整默认 SCENIC 对 9,327 个抽样细胞得到 377 个 regulon，但没有 GLI3 regulon；图中该方法的 GLI3 排名属于 motif 筛选前的 GRNBoost2，不应称为完整 SCENIC 的 GLI3 regulon。后验降低 motif 阈值的敏感性分析不能替代默认结果。各树图的边是所选展示结果，不能直接证明调控或结合。

投稿前仍需由作者完成：

1. 公开或提供项目实际使用的大型处理后输入，或建立可在新环境中验证的原始数据处理流程；原论文数据地址本身不能直接生成本项目全部中间文件。
2. 在独立的新环境完成依赖安装及 Jupyter 交互运行；如要宣称原始数据端到端可复现，还需从头重跑 Pando 和 SCENIC，而不是只恢复检查点。
3. 核实项目衍生数据的具体样本映射、授权和伦理要求；补充作者、引用、图注、数据和代码可用性声明。
4. 如要声称模型优于基线或直接调控，应补充预先定义的独立评价和相应实验验证。
